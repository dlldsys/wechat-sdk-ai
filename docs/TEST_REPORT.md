## 未覆盖功能说明

低覆盖率模块主要是由于以下原因：

1. **HTTP 客户端 (http/index.ts)**
   - 需要实际网络请求
   - 建议使用 Mock 服务器进行集成测试

2. **小程序/公众号 API (mp/*, official/*)**
   - 依赖微信服务器响应
   - 建议使用 Mock 服务器测试

3. **Redis/File 缓存**
   - 需要外部依赖 (Redis 服务/文件系统)
   - 建议使用集成测试

## 改进建议
